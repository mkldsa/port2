윤석희 포트폴리오 V32 — 긴 상세페이지 표시 폭 수정

압축을 완전히 풀고 index.html을 엽니다.
코링클 제품 상세의 버터향김치·스윗불고기·청양고추&갈릭·3종 트리오 탭을 확인하세요.

긴 상세 이미지가 원본 픽셀 폭(70–103px)으로 좁게 표시되던 설정을 수정했습니다.
PC에서는 본문 안에서 최대 1040px, 모바일에서는 본문 너비에 맞춰 표시합니다.
세로 비율과 전체 내용은 유지하며 이미지 파일 자체는 변경하지 않았습니다.
현재 긴 상세 JPG는 축소본이라 확대 시 흐릴 수 있습니다.
선명한 글자를 위해서는 해당 4종의 고해상도 긴 이미지 원본으로 교체해야 합니다.

V31에서 교체한 코링클 메인 이미지 3종, 인트로, 5초 자동 롤링,
전체 23개 작업과 기존 등록 방식은 그대로 유지합니다.

GitHub Pages에는 portfolio_design_v32 폴더의 내용물 전체를 올립니다.
빌드·npm 설치는 필요 없습니다. 자세한 방법은 PROJECT_UPLOAD_GUIDE.txt를 확인하세요.
v32.css / v32-responsive.css는 현재 디자인과 반응형입니다.
각 코드 파일 전체의 TXT 사본은 source_txt 폴더에 포함했습니다.

표시 폭 설정·파일 연결·원본 이미지 보존을 확인했습니다.
이 환경에서는 로컬 페이지의 실제 브라우저 시각 검수를 수행하지 못했습니다.
