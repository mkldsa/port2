윤석희 포트폴리오 V34 — 롤링 속도·웹 작업물 화면·사이트 버튼 수정

압축을 완전히 풀고 index.html을 엽니다. concept-b.html에도 같은 수정이 반영되어 있습니다.

1. 대표 작업 자동 전환을 5초에서 4초로 변경했습니다.
   일시정지, 키보드 탐색, 화면 밖 이동, 다른 탭과 모션 줄이기 설정은 유지합니다.
2. 루네 홈페이지와 프로모션의 요청한 안내 문구를 삭제했습니다.
3. 제공한 루네 홈페이지 캡처를 메인 배너, 작업 목록, 상세 표지와 전체 화면 이미지에 적용했습니다.
   모델 캠페인 이미지와 원래 사이트 파일도 보존했습니다.
4. 웹사이트·쇼핑몰 작업은 메인 배너, 작업 목록과 상세 상단에 사이트 보기 버튼을 강조했습니다.
   카드 링크와 사이트 버튼은 별개의 링크이며 새 창으로 사이트를 엽니다.
   사이트 주소가 없는 GARDEN 5 LIFE는 저장된 화면을 여는 화면 보기 버튼입니다.
5. 웹 작업 상세의 대표 이미지는 실제 홈페이지 화면을 보여줍니다.
   전체 페이지 이미지와 원래 추가 작업 이미지는 아래 갤러리에서 유지됩니다.
