PORTFOLIO v18
=============

v17 구조를 유지하면서 요청한 부분만 수정.

1. 레코드 중앙 이동
- 기존 56.5% → 52.5%
- 화면 중앙 쪽으로 당겨 좌/우 여백 균형 조정
- 오른쪽 selected works와도 충분한 간격 유지

2. 레코드 카테고리 첫 번째에 내 소개 추가
- 00 ABOUT ME
- 01 WEB DESIGN
- 02 E-COMMERCE
- 03 DETAIL PAGE
- 04 GRAPHIC DESIGN

중요:
- 첫 진입은 여전히 01 WEB DESIGN
- 작업물이 첫 화면부터 바로 보이는 장점 유지

- ABOUT ME 상태에서는 오른쪽 SELECTED WORKS 영역이 PROFILE 정보로 변경
- ABOUT ME에서 레코드를 클릭하면 about.html로 이동

PROFILE 우측 표시 정보
- YOON SEOK HEE
- WEB DESIGNER / PUBLISHER
- 짧은 소개

3. 우측 하단 메뉴 제거
- WORK / ABOUT / CONTACT 삭제
- 상단 PROJECTS / ABOUT / CONTACT와 중복이라 제거
- 오른쪽 시선 분산 감소
