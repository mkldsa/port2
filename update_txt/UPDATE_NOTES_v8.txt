PORTFOLIO v8
============

메인 수정 내용

1. 중앙 레코드 라벨 다시 정리
- v7의 정보가 너무 많은 '레코드 문서' 느낌 제거
- 종이 라벨 베이스와 텍스트를 두 레이어로 분리
- 종이 라벨 자체는 레코드와 같이 회전
- 텍스트는 항상 읽히도록 고정
- 표시 정보는 최소화:
  YOON SEOK HEE
  PORTFOLIO / 2026
  TRACK 01
  SIDE A / 33⅓ RPM
  SELECTED CATEGORY / WEB DESIGN
- 과한 catalog / stereo / series / 여러 미세 텍스트 삭제

2. hover 광원
- v7보다 약 20~25% 정도 강하게
- 한 방향 beam/streak 없음
- 마우스 위치의 둥근 주광 + 반대편 약한 bounce light
- 기본 record reflection도 양쪽에 나뉜 아주 약한 반사로 교체

3. 레코드 자체 디테일
- 중앙 라벨 바깥 검은 경계 두께 축소
- run-out groove 조금 선명하게
- 외곽 edge를 얇게 보강

4. 추가로 발견한 디테일 수정
- 오른쪽 카테고리명이 뷰포트 끝에서 잘리는 문제 완화
- category orbit radius 54.5 → 51.8로 안쪽 이동
- 카테고리명 최대폭 / ellipsis 보완
- 중간 PC 폭에서 orbit 위치 보정
