PORTFOLIO v6
============

수정 내용

1. 레코드 hover 조명 버그 수정
- v5에는 상태값/렌더링 코드는 있었지만 실제 pointermove 이벤트가 빠져 있었습니다.
- v6에서 pointerenter / pointermove / pointerleave를 실제 recordButton에 연결했습니다.
- 레코드 원 내부에서만 조명이 켜집니다.
- 마우스 좌표를 % 좌표로 계산하고 부드럽게 보간합니다.
- 기존 고정 위치 conic hover light는 완전히 비활성화했습니다.

2. 중앙 레코드 라벨 전면 재디자인
- YOON SEOK HEE / PORTFOLIO 곡선형 레트로 타이포 제거
- 레코드 홈만 회전하고 중앙 라벨은 고정되는 구조로 변경
- editorial / index 스타일:
  YOON SEOK HEE
  PORTFOLIO / 2026
  큰 카테고리 번호 01
  SELECTED CATEGORY / WEB DESIGN
- 카테고리 전환 시 중앙 01 / 카테고리명도 자동 변경
- 텍스트가 짧게 재인쇄되는 모션 추가

3. 스크롤 방향과 레코드 회전 방향 연결
- 아래로 스크롤: 정방향
- 위로 스크롤: 역방향
- 다음 스크롤 전까지 해당 방향으로 천천히 계속 회전
- 키보드 / 모바일 swipe도 방향에 맞게 회전
- 카테고리 직접 클릭도 가까운 이동 방향을 기준으로 회전

변경 파일
- index.html
- assets/css/main.css
- assets/js/main.js


추가 확인
- pointer light opacity에 CSS calc 곱셈을 사용하지 않도록 수정.
- JS에서 계산한 0~1 강도를 CSS 변수에 그대로 전달해 Chrome/Safari 계열에서도 표시되도록 처리.
