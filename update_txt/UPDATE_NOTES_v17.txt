PORTFOLIO v17
=============

이번 버전은 '작업물을 클릭 후 보여주는 구조'를 바꾸는 실험 버전입니다.

첫 화면 정보 구조
1. 왼쪽 상단
   WEB DESIGNER / PUBLISHER
   브랜드의 분위기를 화면으로 설계하고,
   실제로 동작하는 웹까지 구현합니다.
   ABOUT ME ↗

2. 왼쪽 중앙
   현재 카테고리 번호
   SELECT CATEGORY
   WEB DESIGN
   카테고리 한 줄 설명

3. 중앙
   기존 LP 레코드 유지
   스크롤 시 카테고리 변경
   클릭 시 기존 전체 프로젝트 패널 오픈

4. 오른쪽
   SELECTED WORKS
   현재 카테고리 작업물 2개를 처음부터 노출
   스크롤로 카테고리가 바뀌면 작업물도 fade/slide로 교체
   각 카드는 바로 상세페이지로 이동 가능

5. 사용법
   기존 큰 HOW TO 카드 제거
   SCROLL TO BROWSE · CLICK RECORD TO VIEW ALL 한 줄만 유지

인터랙션
- 카테고리명/설명 기존의 부드러운 전환 유지
- 오른쪽 작업물도 카테고리 변경 시 함께 교체
- 레코드 hover 문구도 VIEW ALL [CATEGORY]로 자동 변경
- 레코드 클릭은 '현재 카테고리 전체보기' 역할로 유지

가독성
- 클릭 후 나오는 preview panel의 프로젝트 서브카피/메타 글씨 크기도 확대 유지
